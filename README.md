## 它能做什么

一句话：**把它当成一个住在你手机里的助理，你说需求，它自己操作手机去完成。**

| 能力 | 说明 |
|------|------|
| 💬 **离线对话** | 模型跑在手机 NPU 上，断网可用，对话内容不出设备 |
| 👁️ **看懂屏幕** | 读取当前界面的控件树（哪个按钮在哪、写了什么），据此决策 |
| 👆 **操作手机** | 点击 / 长按 / 滑动 / 输入文字 / 返回主页 —— 经由无障碍服务执行 |
| 📂 **读写文件** | 在应用私有工作区内读、写、列目录、搜索 |
| ⌨️ **执行命令** | 内置终端；可进一步安装 Debian 等 Linux 环境（PRoot，无需 root） |
| 🌐 **浏览器** | 内置浏览器，模型可自行打开网页、读取内容 |
| 🧩 **技能（工具调用）** | 50+ 内置工具，按你授予的权限动态启用；模型自主决定调哪个 |
| 🎭 **角色与记忆** | 自定义人格（系统提示词），跨会话长期记忆 |
| 🔌 **MCP 扩展** | 可接入 MCP 服务，把外部工具挂给模型 |
| 🎛️ **参数可视** | 回复下方实时显示解码速率与首 token 延迟；温度 / top-p / 上下文可调 |

> **完全离线是默认状态**：应用不内置任何云端模型。如果你愿意，也可以在「模型提供商」里自行接入 OpenAI 兼容端点或 Anthropic（此功能默认不使用）。

## 我的手机能跑吗

核心要求：**Android 14 及以上（arm64）**。推理后端按下面顺序自动选择：

| 你的设备 | 后端 | 状态 |
|----------|------|------|
| 骁龙 8 系（Hexagon NPU） | **NPU（HTP）** | ✅ **推荐**；HTP v73/v75/v79/v81 四代后端已打包，其中 v79 实测通过 |
| 其它 arm64 手机（天玑 / 麒麟 / 老骁龙…） | **CPU** | ⚠️ 能跑，但明显更慢（约 1/3 速度） |
| Adreno GPU（Vulkan） | GPU | ❌ **输出乱码**，实测不可用，请用 NPU 或 CPU |

### 需要 root 吗？**不需要。**

无 root 是本项目的设计目标之一，不是"凑合跑"：

| 能力 | 无 root |
|------|---------|
| 本地模型推理 / 对话 / 记忆 / 浏览器 / 文件工具 | ✅ 完整可用 |
| 屏幕观察与点按 | ✅ 走**无障碍服务**（普通权限） |
| 终端 + Linux 环境 | ✅ 走 **PRoot**（用户态方案）；有 root 时自动升级为 `chroot` |
| 模型下载与管理 | ✅ 完整可用（无 root 时模型落外部目录，读取略慢） |
| 联系人 / 短信 / 通话 / 相册 / 日志 / 改系统设置等约 27 个工具 | ❌ 需要 root；**未授权时会被自动摘掉**，不报错 |
| 系统助手接管 / 小爱同学 hook | ⭕ 需 LSPosed（**可选增强，不装不影响使用**） |

> ⚠️ **一条未验证项**：NPU 路径**尚未在未 root 的设备上实测**（开发机是 root 的）。
> 理论上不需要 root（应用自带全部 FastRPC/DSP 库），欢迎未 root 用户跑通后回报。
> 另：无 root 时无法自动清理后台来腾内存，大模型加载更容易被内存预检拒绝，可手动清后台绕过。

📖 完整机型矩阵、HTP 代际表、量化格式白名单、权限分级见 [`docs/COMPATIBILITY.md`](docs/COMPATIBILITY.md)。

**内存是硬门槛**（比芯片型号更关键）：

| 模型规模 | 需要可用内存 | 16GB 机型 |
|----------|--------------|-----------|
| 0.6B ~ 1.7B | ≈ 1~2 GB | ✅ 轻松 |
| 4B（推荐） | ≈ 4 GB | ✅ 通常可满足 |
| 8B | ≈ 6 GB | ⚠️ 需先清理后台 |

> 应用内置内存预检：**可用内存不足时直接拒绝加载**，而不是把手机拖进卡死。
> 另有一条温度边界，充电 + 高温时会拒绝重载模型。

📖 更细的机型 / 后端矩阵见 [`docs/COMPATIBILITY.md`](docs/COMPATIBILITY.md)。

## 快速开始（4 步）

### 1. 安装

自行构建（见[开发者：构建](#开发者构建)），或安装你获取到的 `app-debug.apk`：

```bash
adb install -r app-debug.apk
```

首次启动会有引导页，说明数据不出设备。

### 2. 授予权限

进入 **设置 → 权限**，按需开启：

| 权限 | 用来做什么 | 是否必须 |
|------|-----------|---------|
| **无障碍服务** | 让模型能"看屏幕 + 点按" | 要用手机操作类功能才需要 |
| 通知使用权 | 读取通知 | 可选 |
| 使用情况访问 | 判断前台应用 | 建议开启 |
| 位置信息 | 时间/位置类问答 | 可选 |
| 录音 | 语音输入 | 可选 |
| 存储 | 导入本地模型文件 | 导入模型才需要 |

**只开你需要的** —— 每个工具都受对应权限门控，没授权的工具模型根本看不到。

### 3. 下载一个模型

进入 **设置 → 本地模型 → 模型市场**，推荐先点 **Qwen3-4B · Q4_K_M（2.38GB）**。

- 走系统下载器，**支持后台下载和断点续传**（大文件关屏也能下）
- 也可以「本地导入」：把 `.gguf` 放到手机的 `Android/data/cn.yangrq.weixuan/files/models/`
- 国内网络建议直接用应用内的下载链接（已指向 hf-mirror 镜像）

### 4. 加载并开始对话

模型下载完成后点 **加载**。首次加载需要 **15~25 秒**（要从存储读 2~4GB，受存储速度限制）——
期间对话界面会显示「正在加载本地模型，请稍候」。加载完成后：

1. 回到 **对话** 页，输入你的第一句话，例如：
   - `现在几点了？`（简单问答）
   - `帮我打开微信`（需要无障碍权限）
   - `看看屏幕上有什么`（会读取界面控件树）
2. 回复下方会显示 **tok/s** 与首 token 延迟
3. 想让它动手操作时，确保 App 在前台或允许后台运行（执行期间会有前台服务保活）

## 使用指南

### 对话

- 模型会**自己判断**要不要调工具：简单问答直接回答，需要操作手机时才发起工具调用
- 一次请求可能包含多轮（观察 → 操作 → 再观察），复杂任务耗时更长属正常
- 如果模型回复里出现「正在加载本地模型」，说明引擎在冷启动，等它即可

### 让它操作手机（技能 / 工具）

- 说法尽量贴近日常：`打开设置里的蓝牙`、`在搜索框输入天气`、`往下滑看更多`
- 执行过程中每一步都会在对话里留痕（调了哪个工具、参数是什么、结果如何）
- 想让它连续做多件事，可以一次说完：`打开相册，找到最近一张照片的信息告诉我`

### 终端与 Linux 环境

- **终端**页直接执行 shell 命令
- 需要完整 Linux 时，进 **Linux 环境** 安装 Debian（PRoot 方案，**不需要 root**），随后可安装常见命令行工具
- 模型在获得许可后也能调用这些命令（`run_command`）

### 模型管理

- 支持**随时切换模型**：不同模型适合不同任务（轻量模型快、大模型聪明）
- 模型可以卸载释放内存；不使用时建议卸载，给系统留余量

### 调节行为

| 设置项 | 作用 |
|--------|------|
| 上下文窗口 | 越大记得越多，但更吃内存、更慢；应用会按内存自动选择 |
| 温度 / top-p | 越高越有创造性，越低越稳定 |
| 思考模式 | 关闭后直接作答（更快），开启则保留推理过程 |

> **入选标准**：标准 dense 架构（NPU 可用）、Q4_K_M 单文件 ≤4.8GB、下载源可用。
> 已实测**排除** MoE 与线性注意力模型 —— 前者本机不可行，后者 NPU 结构性不支持，

**给新用户的一句话建议：先用 Qwen3-4B。**

- 它在本机实测的**工具调用准确率 80%+**（26 条真实中文指令评测），足够驱动日常任务
- 2.38GB 的体积在 16GB 机型上稳定可加载
- 想更快 → 换 1.7B / 1.5B；想更聪明 → 换高阶档（先清后台）

## 实测性能

以下为**小米 16GB 机型（骁龙 8 Elite Gen 5 / Hexagon NPU）**上的实测值，随提示词长度与温度浮动：

| 项目 | 实测 |
|------|------|
| 解码速度（4B 模型） | **6 ~ 11 tok/s**（提示词越长越慢） |
| 首 token（提示词预填充） | 约 **600 ~ 1000 tok/s** |
| 前缀复用 | 同一会话内复用率 **99%**（后续轮次 prefill 仅几十毫秒） |
| 模型首次加载 | **15 ~ 25 秒**（2~4GB 从存储读入，受存储带宽限制） |
| 内存占用（4B） | 约 2.9 GB（权重 + 视觉塔 + KV） |

**为什么"越聊越慢"**：解码每生成一个字都要读取全部 KV 缓存，上下文越长读得越多。
实测本机大约 **每 1000 token 的上下文，解码慢 1.4 tok/s**。所以设置里的上下文窗口是速度与记忆的取舍。

## 常见问题

**Q：一直提示"正在加载本地模型"？**
首次加载 2~4GB 需要 15~25 秒属正常。若长时间不动，检查可用内存是否够（设置页有内存预检提示）。

**Q：模型加载失败？**
多半是可用内存不足。清掉后台应用再试；或换更小的模型（4B → 1.7B）。

**Q：为什么它不操作我的手机？**
检查 **设置 → 权限 → 无障碍服务** 是否开启。未授权时相关工具不会下发给模型。

**Q：能断网用吗？**
可以。下载模型之后全程离线，推理、工具调用都不需要网络。

**Q：手机发烫？**
推理本身发热有限，**反复加载模型才是主要热源**。避免频繁卸载/重载，或降低模型规模。

**Q：支持哪些模型格式？**
GGUF。内置 9 个可直接下载；也可以自行导入兼容的 GGUF 文件。

## 开发者：构建

```bash
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

发布包（签名 + 代码压缩，需自备 keystore）：

```bash
export WEIXUAN_RELEASE_STORE_FILE=/path/to/your.jks
export WEIXUAN_RELEASE_STORE_PASSWORD=...
export WEIXUAN_RELEASE_KEY_ALIAS=...
export WEIXUAN_RELEASE_KEY_PASSWORD=...
./gradlew assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```

> **`assembleDebug` 出的包带 `debuggable=true` 且用调试签名，只适合自测，不要用于分发。**
> 正式发布请走 `assembleRelease`（已开启 `minifyEnabled` + `shrinkResources`）。

环境要求：

- Android Studio（AGP 9.3.2，Gradle wrapper 已自带）
- Android NDK（版本见 `gradle/libs.versions.toml`）—— 原生运行时由 llama.cpp 交叉编译而来
- 构建机内存建议 ≥ 8GB（Kotlin 编译较吃内存；内存紧张时可在 `gradle.properties` 用
  `kotlin.compiler.execution.strategy=in-process` 让编译器与 Gradle 共用一份堆）

仓库结构：

```
app/src/main/kotlin/cn/yangrq/weixuan/
├── local/         本地推理：模型目录、内存账本、llama-server 托管
├── agent/         智能体运行时：工具清单、执行循环、模型提供商
├── ui/            Compose 界面
└── ...
app/src/main/jniLibs/arm64-v8a/
├── libllama*.so   llama.cpp 推理运行时（含多模态 libmtmd）
├── libggml-htp-v*.so   Hexagon NPU 后端（v73/v75/v79/v81）
├── libggml-vulkan-adreno.so  Adreno GPU 后端（实验性）
└── libproot_*.so  PRoot Linux 环境支持
```

## 技术栈

| 层级 | 选型 |
|------|------|
| 语言 / UI | Kotlin · Jetpack Compose |
| 推理引擎 | 自建 [llama.cpp](https://github.com/ggml-org/llama.cpp) Android 运行时（NDK 交叉编译，独立进程托管 + OpenAI 兼容本地 API） |
| 算力后端 | **Hexagon NPU（HTP）优先**，CPU 自动回退，Adreno GPU（Vulkan）实验性 |
| 模型格式 | GGUF（Qwen3 / Gemma-3 / Phi-4 / Llama-3.2 / DeepSeek-R1 蒸馏系列） |
| 设备操作 | 无障碍服务 + 前台服务租约 |
| 终端 | PRoot（用户态 Linux，无需 root） |
